# Numerical Conversion

<img width="749" height="405" alt="screen143733" src="https://github.com/user-attachments/assets/6108e1c2-3fdc-401f-861c-a3a92b8f4d13" />

It is a program for converting between decimal, binary, octal and hexadecimal numbering systems. 
It consists of a menu with five different options, choosing a numerical system converts the number entered to the other three systems.

## languages used

- c

## tools used

- **[JDoodle](https://www.jdoodle.com/)**
